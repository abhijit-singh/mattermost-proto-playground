## Compass misuse
- No root-barrel import, restyled cousin or invented chrome found. Every import is a subpath, and local compositions carry headers.
- Judgment finding (Suggestion): a stale value is shown by passing the deleted name as the `Select` `placeholder` while `value` is not in `options` (`PolicyDetailPage.tsx:127-129`). This simulates a shipped branch with a prop that exists for empty states, so it depends on the placeholder staying visible, and a real Select would not show it.
- Judgment finding (Suggestion): the stale-rule mark is a `Tag` beside the `Select` (`PolicyDetailPage.tsx:146-152`) where `frame.md` named `FieldMessage` under the selector. The Tag is allowed there, but it is not linked to the control with `aria-describedby`.
